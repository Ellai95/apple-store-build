# Apple Store 3.8 — Fix 20 (311)

- Панель установки автоматически скрывается после передачи IPA в iOS.
- Добавлен крестик для ручного скрытия панели без остановки установки.
- Одинаковое поведение для каталога и библиотеки.

Скрытие интерфейса не останавливает сервер, передачу IPA или отложенную очистку.
При новой установке панель снова доступна. Ошибки отображаются, даже если пользователь
ранее скрыл панель. Для серверной установки передача файла не означает подтверждённый
успех установки в iOS; скрытие происходит на завершении передачи.
Исправления Bundle ID из архива 19 сохранены.
