# Apple Store 3.8 — Fix 19 (310)

- Редактор Bundle ID открывается сразу, без загрузки IPA.
- ID берётся из метаданных каталога или локального файла.
- Свободный выбор ID и повторная установка с тем же ID для обновления копии.
- Убрана дополнительная проверка ID по шаблону профиля перед подписью.

IPA из каталога скачивается после нажатия «Установить».
При отсутствии ID в карточке доступен ручной ввод. Данные карточки не гарантируют
совпадение с конкретной модифицированной IPA; введённый ID применяется явно.
Обычная установка и существующий механизм подписи не изменены.
