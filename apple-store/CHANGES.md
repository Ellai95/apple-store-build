# Apple Store 3.8

- В библиотеке появилась смена Bundle ID и установка отдельной копии приложения.
- Доступен выбор из локальных IPA и каталога.
- Обычная установка из каталога сохранена.

## Проверка

Новое действие использует локальную копию параметров подписи. Оно не записывает Bundle ID
в общие настройки. Введённый ID сохраняется при повторе операции и проверяется по профилю.
Пользовательский локальный исходный IPA сохраняется; временные файлы новой подписи очищаются
прежним механизмом. После подписи фактический ID проверяется до передачи установки iOS.

Компиляция Xcode и проверки на iPhone выполняются после загрузки архива в GitHub.
