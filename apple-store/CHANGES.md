# Apple Store 3.8 — Fix 18 (309)

- В редакторе отображается исходный Bundle ID из IPA.
- Ограничения профиля сертификата видны до подписи.
- Приложение из каталога подготавливается один раз; установка использует тот же файл.
- Отмена очищает только созданный этой подготовкой файл, оригиналы библиотеки сохраняются.

Профиль сертификата пользователя не предоставлен: реальный запрет нового ID
не обходится. Если профиль ограничен одним ID, для копии нужен совместимый профиль.
Обычный вход установки из каталога и сервер установки не менялись.
