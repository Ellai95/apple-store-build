Публикация Apple Store 4.7

Не запускать до готовности к публикации.
Publish-Update.cmd → полный путь к оригинальной Apple Store.ipa.
Рядом должен лежать release.json из той же сборки GitHub.
Скрипт прочитает актуальные настройки R2, добавит описание версии 4.7 и окно обновления для build 400–439.
Уже обновившимся до 4.7 это окно обновления показываться не будет.
Карточки каталога и текущие цены сохранятся.
Если после загрузки IPA публикация настроек завершится ошибкой, повторите Publish-Config.cmd из этой же папки.
