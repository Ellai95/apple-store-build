# Публикация тестового обновления 4.3

После успешной сборки GitHub запустите Publish-Test-Update.cmd.
Укажите полный путь к Apple Store.ipa, рядом должен лежать release.json.
Профиль test-release-4.3.json включает окно и баннер для сборок 420–429.
Не подписывайте IPA ботом перед публикацией, используйте файл из GitHub.

Скрипт читает актуальные настройки R2, сохраняет цены и оформление,
добавляет описание релиза, загружает IPA и только затем публикует
configuration.json с новой revision. Если настройки ещё не существуют,
проверяется HTTP 404 по публичной ссылке и используется локальный шаблон.

Если загрузка IPA прошла, а публикация configuration.json завершилась
ошибкой, повторите Publish-Config.cmd из ЭТОЙ же папки. Не подменяйте
сгенерированный configuration.json первоначальным шаблоном из архива.
После публикации проверьте обновление в установленной 4.2.

Get-Config.cmd скачивает текущие онлайн-настройки с сохранением локальной
резервной копии. Publish-Config.cmd публикует локальные настройки; для
изменений нужно увеличить revision. Publish-Release.cmd предназначен
для обычной публикации будущих релизов без данного тестового профиля.

Подробные шаги и критерии проверки находятся в START_HERE.txt.
