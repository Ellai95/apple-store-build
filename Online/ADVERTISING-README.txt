УПРАВЛЕНИЕ РЕКЛАМОЙ — APPLE STORE 4.7+

Advertising.json — только реклама и платное отключение. Publish-Ads.cmd читает
СВЕЖУЮ онлайн-конфигурацию и заменяет этот раздел, сохраняя новости, каталог,
ссылки, цены сертификатов и релиз Apple Store. Личные разрешения grants он сохраняет.
Изменяйте рекламу этим скриптом, а не старой копией полного configuration.json.

Кампания:
- id: постоянное уникальное имя. Для новой рекламы используйте новый id.
- enabled: true/false. Общий enabled также должен быть true.
- title: жирный заголовок; text: обычный текст и Markdown:
  **жирные слова**, *курсив*, [ссылка](https://t.me/appleipa095), эмодзи и переносы.
  HTML и выполнение скриптов не поддерживаются.
- imageURL: публичная HTTPS-ссылка на JPG/PNG, либо null без фото.
- icon: эмодзи, например ✨; до 16 символов.
- buttons: до четырёх кнопок {id, title, url}. Только HTTPS-ссылки.
- mode: entry — при новом входе, interval — повторять, once — один раз для этого id.
- intervalSeconds: от 300 до 86400. Для пяти минут: 300.
- priority: от -100 до 100. Большое значение выше в очереди.
- minBuild: 460, maxBuild: null либо последняя разрешённая сборка.
- startsAt/endsAt: null либо UTC-дата вроде 2026-11-01T10:00:00Z.

Повторные окна не накладываются. Между ними минимум пять минут в одном входе.
Возврат из Safari/оплаты быстрее 30 секунд не считается новым входом.
Новый вход после более длительного фона запускает entry, когда нет других окон.
Показ приостанавливается на время подписи/загрузки/установки, системных окон
и других открытых панелей. Таймер действует только пока приложение активно.
Настройки обновляются примерно раз в минуту при открытом приложении;
сразу применить изменения можно обновлением настроек.
Stop-Ads.cmd выключает весь показ, сохраняя кампании и доступ пользователей.

ФОТО:
Загрузите картинку в R2 через rclone, например:
C:\rclone\rclone.exe copyto "E:\photo.jpg" "r2:appleipa-files/apple-store/media/advertising/photo.jpg" --s3-no-check-bucket
В imageURL укажите публичный URL этого объекта. Если фото недоступно,
остаётся заголовок, текст, кнопки и возможность закрыть окно.

БЕЗ РЕКЛАМЫ:
В offers установите свои цены price в рублях, enabled=true у нужных тарифов.
Месяц в шаблоне = 30 дней, год = 365 дней. Названия и срок меняются онлайн.
Заполните paymentDetails своими реквизитами, затем purchaseEnabled=true.
recipient — Telegram получателя чека, сейчас https://t.me/ellai95.
Повторно Publish-Ads.cmd — появится кнопка «Отключить рекламу» и экран оплаты.
Приложение не проверяет банковские платежи: вы проверяете чек вручную.
Кнопка отправки чека открывает ваш Telegram и текст с кодом/тарифом/суммой;
сам чек пользователь прикрепляет в чате.

После проверки чека: Grant-AdFree.cmd → полный 32-символьный код → 30 или 365 дней.
Срок считается с момента выдачи. Повторная выдача заменяет срок для этого кода,
а не добавляет дни к старому. У других пользователей реклама остаётся.
Revoke-AdFree.cmd отзывает разрешение только у указанного кода.
Пользователь нажимает «Проверить доступ» или ждёт очередного обновления данных.
По истечении срока реклама возвращается автоматически при следующей проверке показа.
Код хранится локально и в Keychain, не содержит имя/телефон/Telegram ID.
После удаления приложения/смены сертификата/устройства сохранность кода
не гарантируется: сохраните код и восстановите доступ вручную при необходимости.
Это доступ для установленной копии, а не полноценная авторизация аккаунта.
Реестр содержит только случайные коды и сроки; не добавляйте туда персональные данные.
Онлайн-конфигурация публична. Защиты от модификации клиентского IPA эта схема не даёт.

В стандартном R2 есть бесплатная квота; при превышении квот возможны расходы.
Новый платный сервер для этой версии не требуется. Компьютер нужен только
для публикации настройки/выдачи доступа, не для самого показа рекламы.
