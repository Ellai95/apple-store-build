ИЗМЕНЕНИЯ ОНЛАЙН
Сначала Get-Themes.cmd скачивает актуальную Personalization.json.
Правьте ТОЛЬКО поле services; его можно перенести из этого пакета, если в старом файле поля ещё нет.
Publish-Services.cmd публикует только services, сохраняя Pro-доступы, темы, ранние версии, рекламу и каталог.
При проблемах сети включите Happ и запустите Publish-Services-Happ.cmd.
Скрипт проверяет конфигурацию, делает резервную копию и отказывается записывать поверх чужого свежего изменения.
Потяните список сервисов вниз для обновления на телефоне.

products — порядок карточек.
В каждой карточке: title, subtitle, description, category, color, platforms, enabled, plans.
В тарифе: title, price (рубли), period, detail, enabled. previousPrice — зачёркнутая прежняя цена.
Цена должна быть целым положительным числом; previousPrice, если задана, должна быть выше price.
price:null означает «По запросу». Новый тариф можно добавить без IPA.
Скрыть одну карточку: enabled:false у карточки. Скрыть тариф: enabled:false у тарифа.
Скрыть всю вкладку: services.enabled:false.
Категории: Игры / Нейросети / Монтаж.
Иконки symbol: gamecontroller.fill / sparkles / brain.head.profile / scissors / desktopcomputer / play.rectangle.fill.
Смена встроенных картинок и добавление новых механизмов оформления требуют новой сборки.

СОВМЕСТИМОСТЬ
В 4.7 и прежних сборках новый раздел не появится без установки этого IPA.
Старые сборки игнорируют новое поле services и продолжают получать обычную конфигурацию.
В 4.9 вкладка показывается даже при прежней онлайн-конфигурации: цены берутся из встроенного набора.
Для размещения цен онлайн используйте Publish-Services.cmd после собственной проверки.
