# AppStore+ — исправления после первой проверки на iPhone

## Подготовленные изменения

- VPN открывается новым экраном каталога внутри навигации профиля. Вложенные экраны «Мои IPA», «Обновления», «Избранное», «Сервисы» и «Настройки» используют родительскую навигацию.
- Сохранённая аватарка показывается в строке аккаунта и кнопке профиля.
- Для частоты экрана сохраняется один UIUpdateLink; настройка вынесена из текущего обновления SwiftUI, повторная настройка без изменения значения пропускается. При переходе на исправленную версию тема и частота один раз сбрасываются в «Классическая / Авто». Импортированные приложения и сертификаты при этом не удаляются.
- Неудачный запуск позволяет следующему запуску восстановить безопасные настройки оформления. Добавлена проверка этой логики для следующей macOS-сборки. Причина конкретного вылета без crash log пока не установлена; устранение требует повторного теста на iPhone.
- В карточке приложения и библиотеке добавлены «Параметры установки». После импорта IPA этот редактор открывается автоматически.
- Редактор передаёт движку подписи название, Bundle ID, случайный ID, версию и иконку из фото/файла. Есть параметры mobileprovision, UISupportedDevices, Watch, «Файлов», iTunes, минимальной iOS, ProMotion, игрового режима, URL-схем и локализованного названия. Оригинальный IPA остаётся отдельным источником; настройки не сохраняются глобально.
- Параметры и иконка сохраняются для повторной попытки после ошибки. Обычная установка остаётся доступна.
- Название приложения — AppStore+. Имя следующего файла — AppStore+.ipa.

## Фото установщика

На фото сторонний установщик показывает AppIcon.png и v26.2. В скачанной из Actions IPA проверены настоящие поля: CFBundleDisplayName и CFBundleName — AppStore+, версия 5.0, сборка 492. Показания внешнего установщика не совпадают с метаданными основного приложения. Исправление его собственного парсера здесь не проверялось.

## Бот и автоматический сертификат

- Бот принимает P12 и mobileprovision вместе или отдельно, пароль по умолчанию 1.
- Добавлена подготовка CI IPA для персонализации: старые ресурсы ad-hoc подписи удаляются перед добавлением bootstrap, затем пакет должен быть заново подписан zsign.
- На реальной IPA 5.0 проверены подготовка основы и вставка тестового bootstrap без P12 в приложении.
- Для запуска нужны локально настроенный тестовый BotFather-токен, разрешённый Telegram ID, постоянный master key, рабочий zsign и HTTPS-адрес сервиса. В этой среде живой бот и signer не настроены. Пользовательские сертификаты повторно не запрашивались.

## Выполнено и осталось

Проверки подготовки исходников пройдены. Грамматика 44 подготовленных Swift-файлов проверена; это не проверка типов Xcode. У Python-сервиса проходят 35 тестов, включая HTTP-активацию и работу с тестовыми сертификатами; подпись доставки подменяется тестовым signer.

Новая сборка Actions не запускалась. До объявления готовности остаются Xcode-сборка, повторный запуск на iPhone после смены темы/частоты, применение настроек на тестовой IPA и живая цепочка «Telegram → zsign → установка → импорт сертификата → даты подписки».


## Следующий запрос: установка, копии, платный доступ

Добавлена зелёная неактивная «Загружено» для подтверждённой установки в карточках и основном каталоге. Состояние сохраняется; достоверное удаление сбрасывает его, временно недоступная проверка сохраняет прошлое подтверждение. Неуспешная/отменённая установка не считается успехом. Обновления доступны отдельным действием в разделе обновлений.

В профиль и библиотеку добавлен единый редактор копий: выбрать локальную IPA или приложение каталога, изменить имя, иконку и Bundle ID. Для копии требуется новый ID. Оригинальная карточка не получает статус установленной из-за установки копии.

Подготовлены проверки переходов «установлено → временно неизвестно → удалено» и сохранённого подтверждения. Они должны исполняться в macOS при следующей сборке; здесь проверены подготовка и грамматика Swift, не работа iPhone API.

Полный прайс и спецификация индивидуальных ключей — docs/appstore-plus-paid-access.md. Платные ключи и обязательный корневой экран добавлены следующим этапом: reports/appstore-plus-paid-access-review.md. APNs и новые системные варианты иконки пока не реализованы. Объявление о переходе не публиковалось.
